# Shadow Alghamdi — Portfolio (offline copy)

Double-click index.html to open the site. No server needed.

- All text, projects, skills and links: assets/data.js
- Looks: assets/style.css   Behaviour: assets/site.js
- Contact form: when opened as a file, it opens your email app with the
  message ready (assets/contact-local.js). On a web host it sends through
  Wix Forms instead (assets/contact.js + js/wix/).
- Pictures, video, logo and CV load from the internet (Wix Media),
  so you need to be online to see them.
